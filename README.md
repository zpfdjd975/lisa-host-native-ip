## “原生IP”在丽萨主机这里分三档，买错档才是真踩坑

先把概念理清楚，后面所有选择都建立在这上面。

**机房IP**：数据中心整段购入，IPinfo 这类数据库里 Type 字段显示 `hosting`。TikTok、Netflix、亚马逊的风控库对这类段位太熟了，识别成本几乎为零。

**伪家宽IP**：机房IP挂了个 ISP 的壳，表面上看 Type 显示 `ISP`，底层路由还是机房。浅层检测能骗过去，深度检测不一定。

**真正的原生住宅IP**：直接向当地宽带运营商申请的线路，IP 段真实属于住宅用户，归属地与实际物理位置一致。所谓“双ISP属性”，指 IP 检测工具会同时给出原生和住宅类两个标签——在平台眼里，你就是一个坐在当地家里的普通用户。

丽萨主机主推的是第三种，但它并没有把所有套餐都做成第三种。

最能说明问题的是台湾。`gid=36` 那条线是台湾 BGP 原生段，IP 归属地确实是台湾、也确实由当地分配，但它属于**机房 IP**，不是住宅段。它能解锁动画疯（巴哈姆特）、Netflix、Disney+、KKTV、ChatGPT，价格还便宜，但你要拿它跑 TikTok 或电商多账号，属性不对。真要住宅属性，得选 `gid=17` 的中华电信 HiNet 双ISP住宅动态IP。同样是“台湾原生IP”五个字，一个机房段、一个住宅段，选之前必须看清楚。

## 自己验一遍：四个工具、一条命令

别人说什么是别人的事，机器到手自己测一遍最省心。这套工具组合是目前国内 VPS 圈通用的做法，四个工具各有分工。

**ipinfo.io**：打开就能看到 IP 的 Type 字段。`isp` 是家宽/ISP 类型，`hosting` 是机房，`business` 是商宽。这是最基础的第一道判断。

**Scamalytics**（scamalytics.com）：给出 0 到 100 的欺诈评分，分数越低越干净。0 到 10 分属于优质住宅 IP，25 分以下日常使用可以放心。超过 50 分基本就别指望过风控了。

**ping0.cc**：国内圈子里用得最多的风控值检测，会对 IP 段做人工标注，区分“家宽”和“机房”。

**IP.Check.Place 一键脚本**：整合了 IPinfo、Scamalytics、AbuseIPDB 几个数据库，同时把 Netflix、TikTok、ChatGPT 的解锁状态一起测了。在 VPS 终端里跑一行：


bash <(curl -Ls https://IP.Check.Place)


关于丽萨主机的实测结果，需要说清口径：**多个第三方测评（VPS GO、老狗 VPS 等）记录的丽萨 ISP 类型住宅 IP，Scamalytics 欺诈值为 0，IPinfo 中 Type 显示为 `ISP`**；台湾原生段的欺诈值同样被记录为 0。这些是测评站的转述结果，不是官方公布的数据，你买到的具体 IP 段可能有差异——所以脚本还是自己跑一遍。

一个提醒：只测一个工具容易被误导。同一个 IP 在 A 库显示 `ISP`、在 B 库被标 `Datacenter` 的情况并不少见，尤其是伪家宽。至少交叉看两个，再结合脚本给出的解锁结果判断。
